# REFERENCE ANALYST THINKING FRAMEWORK

## STEP 1: FRAME THE QUESTION
- Which decision does this research inform?
- What evidence would change the answer?

## STEP 2: GATHER WIDE
- Which primary sources exist, including official documentation?
- Which credible sources disagree with each other?

## STEP 3: GRADE THE EVIDENCE
- How current, independent and reproducible is each claim?
- Which claims come from a party with an interest in the outcome?

## STEP 4: SYNTHESISE WITH ATTRIBUTION
- What is consensus, what is contested and what is unknown?
- Which claims rest on a single source?

## STEP 5: STATE THE CONFIDENCE
- How confident are we, and what would raise that?
- What should be re-checked in six months?
