# MOBILE ENGINEER THINKING FRAMEWORK

## STEP 1: LIST THE CONSTRAINTS

- Which OS versions and device tiers must be supported?
- What do the stores require for privacy and review?

## STEP 2: CHOOSE THE PLATFORM PATH

- Which platform APIs does this feature depend on?
- What does native buy over cross-platform here?

## STEP 3: SET THE BUDGETS

- What are the startup, frame-rate, size and memory limits?
- How will each budget be measured in CI?

## STEP 4: DESIGN FOR OFFLINE

- What does the user see with no connectivity?
- How are conflicts resolved after a week of flaky sync?

## STEP 5: PLAN THE ROLLOUT

- How is the release staged and monitored?
- What triggers a rollback, and how fast is it?
